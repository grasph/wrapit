# Implementing custom wrappers

WrapIt! supports integration of code wrapping some types and methods provided separetly. For this, two hook functions are provided:

    void end_add_type_hook(jlcxx::Module&)
    void end_hook(jlcxx::Module&)
    
The first is called between the definitions of the type wrappers and of the methods: WrapIt! first wraps all the types and then all the methods; it is an easy way to have the types of method arguments defined by the methods, as required by CxxWrap. The second function is called after all the wrappers have been defined.

Implement the hooks in a source file you link togteher with the code generated by WrapIt!. Use the instance of the Module class to add the wrappers. The generated code includes default implementations of the hooks that do nothing.  These implementations are defined as weak symbols, so your implementations override them.

Add the types wrapped by your hooks in the list provided by the `custom_wrappers` configuration parameter. This tells WrapIt! not to generate wrappers for these types and, for classes, their methods. It does not prevent the generation of wrappers for other methods that would use those types. For global functions or isolated methods, use the veto file to prevent the generation of wrappers.
